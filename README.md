# EMERGENCE — Lucia Fontanelli

A changing imaginary landscape for an artist portfolio. Each selected work is a summit; contour lines form a continuous terrain. Filters raise and submerge projects rather than simply hiding them.

## Run

```bash
npm install
npm run dev
```

Open `/concept` for the interactive presentation and `/studio` for the landscape experiment. Initial project symbols, coordinates, taxonomy and object associations are proposed, not final.
