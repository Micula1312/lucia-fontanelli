# EMERGENCE — Lucia Fontanelli

Interactive concept study for a portfolio-as-landscape. Every work is a summit in a continuous imaginary topography, with contour lines and an object at each peak. Filters reshape the terrain rather than merely hiding cards.

## Preview the concept

Open `concept/index.html` in a browser. This initial version is **dependency-free HTML, CSS and JavaScript**. `index.html` redirects to the concept; `studio/index.html` links to the live landscape section.

The repository is ready to grow into the production site, with an editable landscape studio, photographic cutouts and full project pages. We can migrate the concept into Astro components at that stage without losing the underlying interaction model.

## Current functions

- Contour isolines generated with marching squares from a continuous height field
- Objects placed at peak coordinates, labels and hover readout
- Navigation filters for Selected Works, Curatorial Practices, Collaborations
- Elevation control, axonometric view and plan view
- Proposal for the four overlapping research territories: Landscape, Body, DIY/DIT, Feminism
- An object atlas drawn from the supplied portfolio

**Editorial caveat:** the symbols, objects, positions, peak parameters, category assignments and research affinities are proposals to review with Lucia. No private contact/address details from the supplied CV are included.
